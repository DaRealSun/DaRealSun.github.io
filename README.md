# CSC 640 documentation

Hugo site starter for the Campus Equipment Loan API. This contains planning material, not completed HW4/HW5 evidence.

Preview with `hugo server`; build with `hugo --minify`. On this Windows machine, the portable executable is `../tools/hugo/hugo.exe` from this folder.

After publishing this repository as `DaRealSun.github.io`, choose **Settings -> Pages -> Source: GitHub Actions**. The included workflow builds Hugo and deploys the output. Check the workflow and open the live site before claiming HW1 row 4-4.

Use `content/` for report chapters and dated progress; `slides/` for Marp source. Add actual screenshots, results, comparison memo links and final exports as they are produced. The workflow does not export Marp or PDF files.
